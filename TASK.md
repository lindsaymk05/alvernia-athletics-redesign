# Alvernia Athletics Website Redesign

## Audience
The main audience is Alvernia University students, student-athletes, prospective student-athletes, families, and fans who visit the athletics website.

## Problem
The athletics website contains many different teams, schedules, news stories, and other resources. Visitors may have difficulty quickly finding the information they need. The homepage could be more organized and easier to navigate, especially on mobile devices.

## Goal
Create a more modern and organized Alvernia Athletics homepage that helps visitors find sports information and important athletics resources more easily.

## Planned Improvements
- Create a cleaner homepage with clear navigation.
- Add a searchable sports directory.
- Include links to team pages and schedules.
- Organize important athletics resources into sections.
- Make the website responsive for phones and computers.
- Use Alvernia's maroon and gold branding.

## Acceptance Criteria
1. A visitor can find a sport using the sports directory and access its official team page.
2. A visitor can locate important athletics resources, such as schedules and news.
3. The navigation and page layout work on both desktop and mobile screens.
4. A visitor can use the keyboard to navigate important links and controls.
5. Searching for a sport that does not exist displays a helpful empty-state message.

## Project Scope
This project focuses on redesigning the Alvernia Athletics homepage. It is an independent student prototype and does not replace or modify the official Alvernia Athletics website.

## Limitations
The prototype depends on links to the official athletics website. Some content and information may change, so links and destinations must be checked before submission.
