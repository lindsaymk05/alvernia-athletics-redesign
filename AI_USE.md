# AI Use Documentation

## How I Used AI
I used ChatGPT to help plan and build my Alvernia Athletics website redesign. I explained that I wanted to make the existing athletics homepage more organized, modern, and easier for visitors to navigate.

AI helped me create the HTML, CSS, and JavaScript for the redesigned homepage. It also helped organize the different sections, create a searchable sports directory, and make the website responsive for mobile devices.

## My Decisions
I made the decision to focus on the Alvernia Athletics homepage because I am familiar with the athletics department and understand the importance of making sports information easy to find.

I chose to use Alvernia's maroon and gold colors and include sections for sports, schedules, news, and important resources.

I also decided to keep the redesign focused on navigation rather than adding unnecessary features like a live chatbot or paid API.

## Changes and Judgment
I reviewed the AI-generated design and focused the project on features that would actually help visitors. I chose a searchable sports directory because visitors should be able to find a team without searching through multiple pages.

I also kept the official athletics website as the destination for existing team information rather than creating information that could become outdated.

## Limitations
AI helped create the code, but the website still needs to be tested. Some links may need corrections, and the prototype does not automatically update when information on the official athletics website changes.

This project is an independent student redesign and is not an official replacement for the Alvernia Athletics website.
