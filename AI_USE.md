# AI_USE.md

## Project
Alvernia Athletics Website Redesign

## AI Tools Used
I used ChatGPT as an AI coding assistant to help plan, write, organize, and improve the HTML, CSS, and JavaScript for my redesigned Alvernia Athletics homepage.

## How I Used AI
- Helped organize the homepage and decide which sections would be most useful to visitors.
- Helped create the sports directory, search bar, and sport filters.
- Helped make the website responsive for phones and smaller screens.
- Helped add keyboard accessibility and an empty search message.
- Helped update the design to use Alvernia Golden Wolves branding and an official athletics video.

## My Decisions
I chose to focus on making the athletics homepage easier to navigate for students, student-athletes, prospective athletes, families, and fans.

I decided to keep the design simple and organized instead of adding unnecessary features. I also chose not to add a live chatbot, paid API, or complicated 3D features because they were not necessary for the main purpose of the redesign.

I reviewed the design and requested changes when the original logo did not display correctly. I also chose to use the Golden Wolves athletics identity and an Alvernia video instead of keeping the original static background image.

## Limitations
This is an independent student redesign and not the official Alvernia Athletics website. Official schedules, team information, and news remain on AUWolves.com. Some external links and embedded media depend on the official website and YouTube being available.
